# 探栏

中文名：**探栏** · 前缀 `probe` · 端口 **8100**

## 骨架（新骨）

**传感报文装载 → 标定/质控门槛入栏 → 站点汇总物化 → 坏点旁路 → 栏账互证**

| 对比 | 潮切 | 对拍 | **本仓** |
| --- | --- | --- | --- |
| 拓扑 | 事件时入窗→关窗 | 双轨对齐 | **质控门槛入栏→站点汇总** |
| 在途 | 入窗缓冲 | 悬账 | **入栏缓冲（过门槛未汇总）** |
| 产物 | 窗切片 | 对齐差+结论 | **站点汇总账** |
| 旁路 | 迟到匣 | 悬账缺边 | **坏点匣（未过门槛）** |

皮：环境监测传感站（大气/水质探头）。去皮：**标定质控门槛 + 入栏 + 汇总物化 + 坏点旁路 + 栏贯验**。  
禁止做成运维工单、告警大屏、传感器 CRUD。禁止抄潮切窗号/对拍左右轨命名。

## 跨站禁混汇总（已落子）

栏规 `禁混汇总` 选择形态（`关`/`甲`/`乙`，默认关，不改基线 happy path）：

- **甲 切流账册拒拼**：异站报文拒进本趟正式汇总，留在在栏缓冲，站界裁决钉指纹；正式汇总只含本站（锚站）。
- **乙 双写两轨**：本站进正式 `站点汇总账`；异站物化进只读 `影子归档`（汇总账内命运=`影子归档`，正式读只取命运=`已汇总`），两轨读引用不同。
- 锚站：栏规 `锚站` 显式钉，或同栏首站粘性；`POST /api/站界/换站` 换站，与结栏互斥（线程闸+库锁，撞闸 409）。
- 结栏单事务同成同败；栏贯验影子不计正式，影子误充正式即撕裂。

接口：`GET /api/站界/裁决`（只读，正式/异站站点集）· `GET /api/站界/影子归档`（只读）· `POST /api/站界/换站`。
